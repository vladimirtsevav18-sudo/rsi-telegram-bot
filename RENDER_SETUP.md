# Почасовой RSI-сканер

Настройки Render Cron Job:

- Repository: https://github.com/vladimirtsevav18-sudo/rsi-telegram-bot
- Branch: cmc-bybit-hourly
- Runtime: Python
- Region: Frankfurt
- Build command: python -m py_compile scanner.py
- Start command: python scanner.py --once
- Schedule (UTC): 1 * * * *
- Auto deploy: No
- Минимальный доступный вычислительный тариф; минимум $1/месяц за cron, далее по длительности работы.

В Render Environment необходимо вручную добавить CMC_API_KEY, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID. Секреты не помещать в GitHub. Старые TOKEN / CHAT_ID новой программой не используются.

После сохранения переменных выполните Trigger Run и проверьте Runs / Logs и сообщение Telegram. Отсутствие переменных завершает запуск ошибкой. До настройки переменных и первого успешного запуска бот не считается работающим.

Сканер: TOP-100 CMC, объём CMC > $20 млн, спотовая пара Bybit USDT, Wilder RSI(14), строго <35 или >65. Только закрытые последовательные часовые свечи; требуется не меньше 200. Монеты без пары/истории пропускаются. В отчёте указано число пропусков; полное отсутствие покрытия считается ошибкой, а не отсутствием сигналов. Совпадение тикеров — способ сопоставления пары; нестандартные названия пар не подбираются автоматически.

Проверены локально: RSI на эталонной последовательности, исключение незакрытой свечи, отклонение устаревших свечей, отказ при нулевом покрытии. Живой запуск CMC → Bybit → Telegram пока не выполнен.
